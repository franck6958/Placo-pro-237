# Livrables PLACO PRO 237

- `wordpress/` : le thème et les photos prêts à installer sur WordPress (voir `wordpress/LISEZ-MOI.md`). Régénérés avec `npm run build:wordpress`.
- `placo-pro-237.html` : le site en une seule page HTML autonome.
- `photo/` : logo officiel, charte graphique et photos retouchées d'origine.
- `PLACO-PRO-237-presentation.mp4` : vidéo de présentation du site.
- `video-demo/` : le script qui enregistre cette vidéo (`npm install`, puis `node record.mjs`).
